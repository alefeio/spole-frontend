## Regras em todo prompt

1. Ler `web/docs/00-product/frontend-overview.md` e o mapa de contrato.
2. Não alterar `/api` sem autorização.
3. Não chamar a API diretamente em componentes — usar a camada centralizada.
4. Respeitar defasagem de 1 sprint em relação ao backend.
5. Marcar pagamento de reserva de arena e recorrência como **pendente** até estabilização.
